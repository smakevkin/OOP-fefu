# Техническое задание (ТЗ) на разработку сайта-агрегатора товаров и услуг на территории кампуса ДВФУ

# 1. Общие требования
- Сайт должен быть адаптивным и корректно отображаться на всех устройствах (ПК, планшеты, смартфоны).

- Интерфейс интуитивно понятный, с упором на удобство для студентов и сотрудников.

- Поддержка русского языка (опционально — английского для иностранных студентов).

- Реализация безопасных способов оплаты (карты, СБП).

# 2. Функциональные требования

## 2.1 Главная страница
- Лента популярных товаров/услуг.

- Быстрый поиск по категориям (еда, учебники, аренда и т.д.).

- Блок с новостями кампуса (интеграция с соцсетями ДВФУ).

## 2.2. Каталог товаров
- Фильтры: категория, цена, локация (корпус, общежитие).

- Карточки товаров с фото, описанием, контактами продавца.

- Кнопка "Купить" или "Написать продавцу".

## 2.3. Каталог услуг
- Услуги репетиторов, доставки, ремонта техники и пр.

## 2.4. Личный кабинет (ЛК)
- Для покупателей: история заказов, избранное, отзывы.

- Для продавцов: добавление товаров/услуг, статистика.

- Авторизация через почту ДВФУ или соцсети.

## 2.5. Система заказов
- Корзина с выбором оплаты онлайн или при встрече.

- Уведомления в Telegram/email о статусе заказа.

## 2.6. Админ-панель
- Модерация объявлений 
- Блокировка пользователей.

# 3. Дизайн и интерфейс
- Минималистичный стиль с фирменными цветами ДВФУ (синий, белый).

- Адаптивные карточки товаров, удобные фильтры.

# 4. Технические требования
- Golang

- Vue.js

- Docker

- PostgresSQL

# 5. Безопасность
- Верификация продавцов через почту @dvfu.ru.

- Защита от SQL-инъекций.
